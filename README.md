
# Collage

This website is a three-page collage exploring different forms of visual and textual expression through images, music, and literature.

The first page is a collection of mouths and teeth, arranged using CSS Grid with interactive hover effects.

The second page is a horizontally scrolling collage of lyrics from Daniel Caesar's "Please Do Not Lean."

The third page is a collection of photographed and annotated passages from Fyodor Dostoevsky's *The Meek One*, arranged in a dense CSS Grid layout.
I took a more static approach to be the opposite of the blue page.

Each page uses a different grid layout to explore how images and text can be arranged and experienced on a screen.

## Tools Used

- HTML and CSS
- Visual Studio Code
- CSS Grid for page layouts
- GitHub Desktop and GitHub Pages for publishing
- ChatGPT (OpenAI) for troubleshooting HTML and CSS errors, understanding CSS Grid properties, and debugging layout issues.
  - most helpful for debugging code and github errors
  - very unhelpful in trying to set up my grid in the way i wanted it to look so i used chrome's inspect and grid lines to map out where I wanted to      put my images.
